# PROGETTO MY_EBOOK – INDEX MANAGER E MODALITÀ LOCALE

## Contesto

Voglio estendere la mia applicazione **MY_Ebook Android**, attualmente funzionante, per permettere anche ad altri utenti di importare e consultare il catalogo dei propri ebook, eventualmente esportato da Calibre.

Repository GitHub:
https://github.com/Atombesi/my_ebook

L'app è sviluppata con React, TypeScript e Capacitor per Android.

**Vincolo fondamentale: l'app attuale funziona correttamente e non deve essere compromessa. Non modificare alcun file senza una mia autorizzazione esplicita.**

## 1. Obiettivo

Realizzare due componenti:

**A. MY_Ebook Index Manager**

Una piccola applicazione web, pubblicabile su GitHub Pages, utilizzabile dal browser senza installare software sul PC.

Deve permettere di:

- Importare cataloghi CSV esportati da Calibre.
- Importare CSV generici o file XLSX con struttura predefinita.
- Visualizzare e correggere i dati bibliografici.
- Individuare duplicati ed errori.
- Aggiungere manualmente libri.
- Generare il file `Ebook_Index.txt` nel formato esatto richiesto da MY_Ebook.
- Riaprire un indice esistente per modificarlo e rigenerarlo.

La conversione deve avvenire localmente nel browser, senza inviare i dati a un server.

**B. MY_Ebook Android**

Aggiungere una seconda modalità di gestione dell'indice, chiamata **Locale**, mantenendo integralmente quella attuale.

## 2. Modalità di funzionamento

Nelle impostazioni prevedere due modalità selezionabili:

### ONLINE

È la modalità attualmente esistente.

Deve mantenere il funzionamento attuale, inclusi:

- Download dell'indice remoto.
- Controllo degli aggiornamenti tramite gli indirizzi configurati.
- Confronto delle date.
- Memorizzazione locale dell'indice.
- Consultazione offline.

### LOCALE

È la nuova modalità.

Deve consentire di:

- Premere un pulsante **Importa indice**.
- Aprire il selettore documenti standard di Android.
- Selezionare `Ebook_Index.txt` dalla memoria del telefono o da servizi disponibili nel selettore, come Google Drive, Dropbox e Nextcloud.
- Verificare la validità del file.
- Visualizzare un riepilogo dell'importazione.
- Chiedere conferma prima di sostituire l'indice esistente.
- Salvare il nuovo indice localmente.
- Aggiornare immediatamente la biblioteca visualizzata.
- Consultare il catalogo senza connessione Internet.

In modalità Locale non devono essere effettuati controlli online degli aggiornamenti del catalogo.

I controlli relativi alle nuove versioni dell'applicazione devono invece rimanere disponibili, indipendentemente dalla modalità scelta.

## 3. Regole di sicurezza

- Conservare un unico catalogo locale.
- Non cancellare il catalogo quando si cambia modalità.
- Non sostituire il catalogo prima di aver verificato il nuovo file e ottenuto conferma.
- Non modificare né cancellare note personali, valutazioni, prestiti e altre informazioni dell'utente.
- Non compromettere l'attuale sincronizzazione online.
- Gestire esplicitamente errori di lettura, file non valido e importazione annullata.
- Mantenere il comportamento attuale alla prima installazione, compresa la generazione dell'indice iniziale.

## 4. Componenti da analizzare

Nel repository Android sono stati individuati:

- `SettingsModal.tsx` – Impostazioni e selettore file.
- `csvService.ts` – Lettura e memorizzazione dell'indice.
- `syncService.ts` – Controllo aggiornamenti e download.
- `App.tsx` – Gestione dei dati e aggiornamento dell'interfaccia.
- `types.ts` – Definizione delle impostazioni.

Il progetto utilizza già `@capawesome/capacitor-file-picker` per importare backup JSON.

Verificare se tale componente può essere riutilizzato per importare l'indice TXT, anche da provider cloud Android.

Non presumere che il selettore possa ricordare automaticamente il file scelto: questa funzionalità è opzionale e richiede una verifica separata.

## 5. Compatibilità dell'indice

Verificare nei sorgenti il formato effettivamente richiesto dall'app.

Il formato atteso, sulla base delle analisi precedenti, è un file di testo separato da punto e virgola, con intestazione contenente una data e righe con:

`Autore;Titolo;Formato`

L'Index Manager deve produrre un file compatibile con il parser Android esistente, senza richiedere modifiche inutili al formato.

Verificare inoltre la gestione di duplicati, caratteri speciali e formati multipli.
